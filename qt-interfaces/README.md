# qt-interfaces

Создание пользовательского интерфейса приложения с использованием инструментов визуального программирования:

| Проект | Описание | Технология |
|-------|--------|-----------|
| qt-designer | Макет интерфейса администратора СУБД | Qt Designer (`.ui`) |
| pure-code | То же, но интерфейс строится программно при запуске | C++ / Qt Widgets (pure code) |
| qml | Прототип бортовой системы автомобиля | QML / Qt Quick |

## Структура

```
qt-interfaces/
├── qt-designer/     # Интерфейс СУБД, Qt Designer
│   ├── main.cpp
│   ├── mainwindow.cpp
│   ├── mainwindow.h
│   ├── mainwindow.ui
│   └── untitled.pro
│
├── pure-code/       # Тот же интерфейс СУБД, но без .ui
│   ├── main.cpp
│   └── 1-1.pro
│
└── qml/             # Бортовая система автомобиля, Qt Quick
    ├── main.cpp
    ├── main.qml
    ├── car.png
    ├── pic.qrc
    ├── qml.qrc
    └── 1-3.pro
```

## Сборка и запуск

Требуется **Qt 5.15+** или **Qt 6** с установленными компонентами *Qt Widgets* и *Qt Quick* (для третьего проекта), а также компилятор C++17.

Все проекты собираются стандартным образом через `qmake` + `make` (или открываются в Qt Creator двойным кликом по соответствующему `.pro`):

```bash
# Пример сборки любого проекта
cd qt-designer
qmake
make
./untitled        # Linux/macOS
# untitled.exe    # Windows
```

## Администратор СУБД

Первые два проекта реализуют одинаковый функционал, отличается только способ построения интерфейса.

### Функционал

- **Дерево объектов** (`QTreeWidget`) - иерархия СУБД: `SQL Database` → `Таблицы`, `Представления`, `Индексы`, `Последовательности`, `Триггеры таблиц`, `Типы данных`.
- **Таблица данных** (`QTableWidget`) с колонками *Название*, *Тип*, *Описание*.
- **Добавление строки** - по кнопке «Добавить данные в таблицу» из полей «Ввод названия» и «Ввод типа данных» (пустые поля игнорируются).
- **Удаление последней строки** - по отдельной кнопке.
- **Меню «Изменить»**:
  - *Добавить новую таблицу* - создаёт элемент в узле «Таблицы»;
  - *Очистить таблицу* - удаляет все строки;
  - *Удалить таблицу* - удаляет последнюю созданную таблицу из дерева.

### Особенности реализации

| | `qt-designer/` | `pure-code/` |
|---|---|---|
| Файл формы | `mainwindow.ui` | отсутствует |
| Связи сигнал/слот | в `.ui` через `<connections>` | `connect(...)` в конструкторе |
| Слоты | `slot1`…`slot5` | `addData`, `clearTable`, `addTable`, `removeTable`, `loadTable`, `removeLastRow` |
| Хранение данных | в таблице (без сохранения) | `QMap<QString, QList<QStringList>>` - данные таблиц сохраняются при переключении |
| Сборка | `untitled.pro` | `1-1.pro` (single-file, `#include "main.moc"`) |

## Бортовая система автомобиля (QML)

Приложение на `Qt Quick` / `QML` с навигацией через `StackView`. Состоит из трёх экранов.

### Экраны

1. **Главное меню**
   - показатели скорости и погоды, модель `BMW X6 M`, изображение автомобиля.
   - кнопки «Информация» → информационный экран, «Настройки» → экран настроек.

2. **Информация**
   - характеристики авто: марка, модель, мощность, расход топлива, объём двигателя, пробег.
   - кнопка возврата в главное меню.

3. **Настройки**
   - ползунки: яркость фар, громкость звука, температура в салоне.
   - выпадающий список цвета подсветки (`Фиолетовый`, `Белый`, `Красный`, `Мерцающий`).
   - кнопка возврата в главное меню.

## Стек

- **C++17**
- **Qt Widgets** - `QMainWindow`, `QTreeWidget`, `QTableWidget`, `QSplitter`, `QMenuBar`, `QAction`, `QInputDialog`, `QMessageBox`
- **Qt Designer** - файлы `.ui`
- **Qt Quick / QML** - `ApplicationWindow`, `StackView`, `ColumnLayout`/`RowLayout`, `Slider`, `ComboBox`, `Button`
- **Qt Meta-Object System** — сигналы/слоты, `Q_OBJECT`
